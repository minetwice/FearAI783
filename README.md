# 🚀 FearAI - Mobile AI Assistant App

**FearAI** is an advanced, ultra-fast mobile AI app designed specifically to run seamlessly on mobile devices (including 6GB RAM phones) with **100% Free API access**.

---

## ✨ Features
- 🎮 **Minecraft Mod & Plugin Developer**: Full support for Java Bukkit/Spigot/Paper plugins, Forge & Fabric mods, Bedrock Add-ons (JSON/JS), and Datapacks.
- 💻 **Master Coder**: Multi-language support (Java, Python, C++, JS, Rust, Go, Kotlin, HTML/CSS, Assembly, etc.) with clean formatting and one-click code copy or file download.
- 🧠 **Deep Reasoning Engine**: Step-by-step logic solver for complex architecture, math, and system design.
- 🔍 **Live Web Research**: In-app web search engine for real-time information.
- 🎙️ **Voice Chat**: Speech-to-Text input and Text-to-Speech response capability.
- 🔑 **100% Free Engine & Gemini Key Integration**: Zero-key default engine built-in + easy modal to paste Google Gemini Free API key.

---

## 📱 How to Run / Install on Phone

### Option 1: PWA (Progressive Web App) Installation
1. Serve the app locally or host on Vercel/Netlify/GitHub Pages.
2. Open the URL on your mobile browser (Chrome / Edge).
3. Tap **"Add to Home Screen"** or **"Install App"**.
4. FearAI will install as a native fullscreen app on your phone!

### Option 2: Run locally
```bash
npm start
```
Then open `http://localhost:3000` in your mobile browser.
